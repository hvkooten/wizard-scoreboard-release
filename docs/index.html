Wizard Scoreboard

Wizard Scoreboard is a .NET MAUI app for tracking points in the Wizard card game.

Download for Android (APK)

Current version: v3.5.0

Releases, changelog and older versions

What This App Does

  • Create and manage player groups (3-6 players).
  • Track bids, actual tricks, and score progression per round.
  • Correct the latest round's results after entry.
  • Show the trump color while entering bids (card suits or 4-color palette).
  • Apply configurable Wizard scoring rules, including a score multiplier.
  • Store group-specific settings (including the "bids may not equal tricks" rule per player count).
  • Save games and resume or review them later.
  • Keep track of high scores across games.
  • Read the full Wizard rules or a quick-reference summary.
  • Choose a System, Light, or Dark theme.
  • Accessibility options: bold text and simplified buttons.
  • Keep the screen awake during a game.
  • Report bugs by email or clipboard, with automatic crash detection on restart.
  • Support multiple languages.

How To Install On Android

  1. Download the APK using the button above.
  2. Open the downloaded file on your Android device.
  3. If prompted, allow installation from unknown sources for your browser or file manager.
  4. Complete the install and open Wizard Scoreboard.
